파이썬에서 가변(Mutable) 객체와 불변(Immutable) 객체의 차이

  가변 객체

        가변 객체는 객체를 생성한 후에도 내부의 값을 직접 변경할 수 있는 객체를 말한다.
        값을 변경해도 객체의 고유 주소값이 유지되는 특징을 가지고 있으며
        대표적인 타입으로는 list, dict, set이 있다.
        
  불변 객체

        불변 객체는 객체를 생성되면 그 값을 바꿀 수 없는 객체를 말한다.(상수)
        값을 변경하려고 하면 기존 객체가 바뀌는 것이 아니라 새로운 객체가 메모리에 생성되고
        변수는 새로 만들어진 객체를 가리키게 된다.
        대표적으로 int, float, str, tuple 등이 있는데 파이썬은 기본 자료형이 없기 때문에 
        모든 자료형이 내부적으로 C언어 구조체 기반 Wrapper Class로 구현이 되어있다. (자바의 Integer, Double, String 등)
        그렇기에 값을 변경하면 새로운 객체가 만들어져 메모리에 생성 된 후 기존의 변수는 새로운 객체를 가리키게 되고,
        기존에 있던 객체는 GC의 대상이 된다. tuple 같은 경우는 처음부터 불변 자료구조를 가지고 있다.

판다스에서 view와 copy의 차이

  View

        pandas에서 view는 원본 DataFrame에서 값을 가져왔을 때 
        새로운 객체를 만들지 않고 원본을 가리키는 것으로 
        원본과 메모리를 공유한다(가변 객체와 유사, 메모리 효율 증가)
        원본과 메모리를 공유하기 때문에 view를 수정하면 원본도 함께 수정이 된다.

  Copy

        panas에서 copy는 원본과 연결이 완전히 끊어진 새로운 복사본 객체가 메모리에 생성되는 것을 말한다.(불변 객체와 유사)
        원본과 메모리 공유를 하지 않고 새로 생성되는 것이기 때문에 독립된 메모리를 가지고,
        copy를 수정해도 원본은 수정되지 않는다.
