1. 데이터베이스 언어(SQL) 분류
   
  DQL
  
      DQL이란 Data Query Language의 약자로 데이터베이스 내  원하는 내용을 검색하거나 조회할  때 사용합니다
      ex) SELECT
   
  DML
  
    DML은 Data Manpulation Language의 약자로 데이터베이스에 데이터를 추가, 삭제, 수정 할 때 사용하는 언어입니다.
      ex) insert into, update, delete
   
  DDL
  
    Data Definition Language 의 약자로 데이터베이스의 테이블이나 스키마 등을 만들거나 수정, 삭제 할 때 사용하는 언어입니다.
      ex) create, alter, drop, truncate

2. 테이블을 왜 분리해야 하는가?
   상황: 하나의 ‘주문 테이블’에 [고객 이름, 연락처, 주문 상품, 가격, 배송지]를 모두 몰아서 저장하고 있습니다
   
       하나의 테이블에 모든 내용이 들어 있다면  pk가 여러 개가 될 수 있고 데이터가 필요 이상으로 많아지기 때문에 필요한 데이터를 가져오는 데에 시간이 필요 이상으로 길어질 수 있습니다.

       만약 회원 정보 수정 기능을 사용할 때 수정이 필요한 내용을 찾기 힘들 수 있고, 구매자가 상품 정보나 가격 등 접근하면 안 되는 데이터에 접근할 수 있게 됩니다.

        신규 회원의 경우 회원 정보를 제외한 주문 혹은 상품 내용에 not null이 적용된 게 아니라면 회원 등록 자체가 불가능하게 되기도 합니다. 이를 방지하기 위해 
        회원 테이블 - 주문 테이블 - 상품 테이블 정도로 분리 할 수 있습니다.
