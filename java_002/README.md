클래스와 객체의 정의
  클래스: 객체를 생성하기 위한 설계도 또는 틀
  객체가 가져야 할 속성과 기능을 정의해둔 문서

  객체: 클래스를 바탕으로 메모리상에 구현된 "실제 데이터"
  고유한 속셩을 가지며 클래스에 정의된 기능을 수행

클래스의 구성 요소
  1. 필드부
     객체의 상태를 저장하는 변수가 있는 곳
     클래스 블록 내부에 선언되며 객체가 소멸할 떄까지 데이터를 유지
     색상, 브랜드, 이름, 나이, 전원  on/off 등 명사, 형용사적 성격을 띔

  2. 메서드부
     객체의 동작(기능)을 정의하는 함수
     필드의 값을 읽거나 수정할 수 있고 결과를 반환 할수도 있는 특정 작업을 수행하는 코드의 묶음
     감속/가속, 움직이기 등 동사의 성격을 띔
     
  3. 생성자
     new 키워드를 통해 객체가 생성될 때 호출되어 객체의 초기화를 담당
         (this.변수명 = 변수명; 의 방식으로 힙 메모리에 생성된 객체 내부의 필드 변수들을 초기화하고 생성된 객체의 주소값을 스택 메모리의 참조 변수에 할당하는 과정)
     메서드와 동일하게 생겼지만 반환 타입이 없고 클래스의 이름과 대소문자 모두 동일해야 함
